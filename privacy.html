1. 取得する情報

本アプリはYouTube API Servicesを使用します。所有者の明示的な認証・許可に基づき、実際に提供する機能に必要な範囲で、次の情報にアクセスします。

  • OAuth認証情報：アクセストークン、リフレッシュトークン、許可された権限、認証の有効期限。
  • チャンネル情報：チャンネルID、名称、および許可されたチャンネルの確認に必要な情報。
  • 動画・投稿情報：所有者が用意した動画、サムネイル、タイトル、説明文、動画ID、公開状態、処理状態など。
  • 運営集計情報：所有者が提供した再生回数、視聴時間、クリック率などの集計データ。YouTube Analytics APIによる自動取得は現在の提供済み機能ではありません。今後追加する場合は、必要な権限と用途を説明し、事前に許可を取得します。

Googleアカウントのパスワードを本アプリが取得することはありません。Gmail本文、連絡先、カレンダー情報へのアクセスは要求しません。

2. 利用目的

取得情報は、所有者が承認したチャンネルの照合、動画のアップロードと投稿状態の確認、制作・運営記録の管理、および次の動画を改善するための分析に利用します。Google APIの権限許可は、個別の公開・変更・削除操作への包括的な同意として扱いません。

GoogleまたはYouTube由来の情報を、広告配信・広告ターゲティング、販売、信用判断、汎用AIモデルの学習など、上記と関係のない目的には使用しません。

3. 保存場所と情報の保護

認証情報は、運営者の管理端末のアクセスを制限した設定領域に保存します。公開ウェブサイトや公開リポジトリには保存しません。チャンネル・動画情報と運営記録は管理端末に保存し、必要に応じてアクセスを制限した非公開リポジトリで管理します。認証トークンと秘密鍵は、そのリポジトリにも含めません。

情報へのアクセスは、運営に必要な管理者と、所有者が承認した処理に限定します。Google APIとの通信にはHTTPSを使用します。認証情報の保管が無期限に保証されるものではなく、Googleの仕様や所有者の操作により再認証が必要になる場合があります。

4. 外部提供と限定利用

承認された投稿を行うため、動画・タイトル・説明文などの投稿情報をGoogle／YouTubeに送信します。運営者はGoogle APIから取得した情報を販売せず、第三者の広告やデータブローカーに提供しません。

Google API由来の情報を外部のAI支援ツールなどで処理する場合は、用途・提供先・共有範囲について所有者の事前の明示的同意を得て、目的に必要な情報だけを扱います。認証トークンや秘密鍵は渡しません。汎用AIモデルの学習用途に提供しません。法令への対応、または不正・セキュリティ問題への対処に必要な場合を除き、同意のない外部提供は行いません。

本アプリによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、限定利用（Limited Use）要件を含むGoogle API Services User Data Policyに従います。

Googleにおける情報の取扱いについては、Googleのプライバシーポリシーもご確認ください。

5. 保持期間と削除のご依頼

認証トークンは、所有者が許可した機能の利用に必要な期間保持します。Google／YouTubeから取得したその他のAPIデータは、原則として30日以内に更新または削除します。YouTube Analytics等の統計データを継続保管する場合は、少なくとも30日ごとに認可が有効であり、対象動画が削除されていないことを確認します。

削除を希望する場合は、下記連絡先に対象チャンネルと削除したいデータをご連絡ください。運営者が依頼者を確認したうえで、速やかに、遅くとも依頼から7暦日以内に対応します。Googleで権限を取り消した場合は取得を停止し、関連するAPIデータを30暦日以内に削除します。別途削除のご依頼がある場合は7暦日以内の対応を優先します。

これらは運営者による管理対応です。ローカルの認証情報や運営記録の削除だけでは、YouTube上の公開動画は削除されません。所有者が独自に用意した制作素材・台本はAPI取得データと区別して管理します。

6. Googleの権限を解除する方法

Googleアカウントのアプリへのアクセス管理を開き、YouTube Factoryへのアクセスを取り消すことができます。権限の解除後、本アプリは新たなAPIアクセスを行いません。再び利用する場合は、あらためて認証と許可が必要です。

Google上の取り消しに加えて、保存済みデータの削除を希望する場合は、運営者へご連絡ください。

7. このウェブサイトについて

このサイトはアプリの説明とポリシーの掲載だけを目的とした静的ページです。ログイン、認証情報の入力フォーム、独自のアクセス解析、広告用Cookieは設置していません。配信・安全管理のために、ホスティング事業者がIPアドレス等のアクセスログを処理する場合があります。

メールでいただいた問い合わせ情報は、問い合わせ対応と必要な運営記録のために利用します。
